# User Taste

## Workflow
- Before starting a work session, expects the agent to first read and internalize the project's AGENTS.md (project guide/rules) and confirm the key context before building anything. Confidence: 0.8
- Prefers "just build it" execution: given a feature request, proceed straight to implementation without asking for permission or confirmation at each step — but ask whenever there is a genuine doubt or ambiguity ("any doubt just ask"). Confidence: 0.8
- Expects feature parity across web and Android — when adding a capability (e.g., image picking), it should work on web just as it does on Android, not mobile-only. Confidence: 0.7
